# 🌦️ Weather App

A simple and responsive **Weather Application** built using **HTML, CSS, and JavaScript** that fetches real-time weather data from a public API and displays current temperature, minimum & maximum temperature, humidity, wind speed, pressure, and feels-like temperature for any searched city. <br>
<br>
---

## 🚀 Features <br>
- Search weather by city name <br> 
- Fetches real-time data using Weather API  <br>
- Shows:<br>
  - Current Temperature  <br>
  - Min & Max Temperature  <br>
  - Feels Like  <br>
  - Humidity  <br>
  - Wind Speed  <br>
  - Pressure  <br>
- Clean and responsive UI  <br>
---<br>
## 🛠️ Technologies Used<br>

- HTML5  <br>
- CSS3  <br>
- JavaScript (ES6)  <br>
- Weather API (Fetch API)<br>
